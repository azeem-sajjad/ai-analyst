# 📊 AI Analyst

An AI-powered business analyst application built with Streamlit, Plotly, and Llama3 using Ollama.

The app allows users to:

- Upload CSV or Excel files
- Chat with their data using natural language
- Generate intelligent charts automatically
- Detect trends and insights
- Perform AI-driven business analysis
- Create dynamic visualizations

---

# 🚀 Features

## 💬 AI Chat Analyst
Ask questions like:
- "What are the top insights?"
- "Which region performs best?"
- "Are there any anomalies?"

## 📊 Smart Chart Generation
Generate charts using natural language:
- "Top 10 customers by revenue"
- "Monthly sales trend"
- "Pie chart by region"

Supported charts:
- Bar
- Line
- Pie
- Scatter
- Heatmap
- Histogram
- Area
- Box Plot
- Grouped/Stacked Charts

## 📄 Data Explorer
- View uploaded dataset
- Filter columns
- Download processed CSV

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/azeem-sajjad/ai-analyst.git
cd ai-analyst
```

## Create Virtual Environment

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

---

# Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Ollama

Install Ollama and run:

```bash
ollama run llama3
```

---

# ▶️ Run App

```bash
streamlit run app.py
```
